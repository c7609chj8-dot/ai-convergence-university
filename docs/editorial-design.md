# 참고 PDF 기반 디자인 개편

- 참고: 사용자가 제공한 U PLEAT 홈페이지 스크린캡처 PDF, 2026-11-18.
- 분석 범위: PDF 2페이지를 렌더링하여 검토. 뒤쪽 반복·잘린 화면은 캡처 흔적으로 취급.
- 적용: 검은 히어로, 큰 타이포그래피, 절제된 이미지 조각과 곡선, 여백이 넓은 밝은 본문, 구분선 중심의 과정 소개.
- 브랜드·기관·교육내용은 AI 융합대학의 기존 데이터와 운영 상태를 유지. 참고 사이트의 로고·홍보 문구·솔루션명·이미지는 사용하지 않음.

## 화면 구성

1. 검은 헤더: 기존 한국어 메뉴와 모집안내 동선 유지.
2. 메인: ‘AI를 배우고, 가능성을 만듭니다.’ 두 줄 제목, 기존 생성 이미지 4장을 배경 조각으로 배치, 얇은 곡선 연결.
3. 주요 행동: 교육과정·로드맵 링크, 교육과정 영역으로 이동하는 스크롤 링크.
4. 교육과정: 기초·심화 두 개의 넓은 행, 큰 과정명·설명·미리보기 이미지·관련 링크.
5. 로드맵·프로젝트·교육 방식·FAQ: 가독성과 실제 동작을 유지하면서 중립색·직선·얇은 경계로 통일.
6. 모집안내와 푸터: 검은 배경과 밝은 글자로 마무리.

## 구현

- `app/editorial.css`: 편집형 시각 체계와 반응형 조정.
- `app/page.tsx`: 메인 구도와 교육과정 도입부.
- `app/layout.tsx`: 디자인 스타일 연결.
- 기존 공개 페이지·24주 데이터·FAQ 검색·주차 펼치기·모바일 메뉴 유지.
- 새 이미지 생성이나 백엔드·신청 기능 추가 없음.
- 참고 PDF와 렌더링 파일은 저장소에 업로드하지 않음.
