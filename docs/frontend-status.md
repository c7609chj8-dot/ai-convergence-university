- 작성일: 2026-11-18
- 사용자 결정: 프론트엔드 우선 진행. Next.js 코드를 직접 구현하고 Sites 스킬은 사용하지 않음.
- 현재 사용자 흐름: 홈 → 과정 비교 → 12주 상세/24주 로드맵 → 모집 준비 안내. 질문 검색과 프로젝트 설명으로 보완.
- 데이터 흐름: 버전관리된 정적 콘텐츠 → Next.js 페이지 → 브라우저. 백엔드 API·DB 경계는 이번 범위에 해당하지 않음.

## 제공 화면

- `/`: 홈, 과정 비교, 로드맵 요약, 교육용 프로젝트, 수업 방식, FAQ.
- `/about`: 교육철학·수업 방식·브랜드 표기.
- `/programs`: 과정 비교.
- `/programs/basic`, `/programs/advanced`: 주차 12건씩, 모두 펼치기/닫기, 선수조건·준비상태.
- `/roadmap`: 전체 24주, 해당 과정 주차로 이동 시 자동 펼침.
- `/projects`, `/projects/qr-maker`, `/projects/image-to-pdf`, `/projects/daily-assistant`: 교육용 디자인 예시·목표 기능 설명.
- `/faq`: 9개 질문, 분류·검색·검색 없음·초기화·펼치기.
- `/schedule`, `/apply`: 확정 회차 없음, 접수 기능 없음.
- `/instructors`, `/notice`, `/contact`: 실제 정보 준비 상태. 허위 경력·공지·문의처 없음.
- `/privacy`, `/terms`: 실제 서비스 제공 범위·법적 문안 준비 현황.
- 잘못된 경로는 404 응답, 오류 시 재시도 화면 제공.

## 주요 설계

- 공개 콘텐츠는 서버 컴포넌트 중심으로 렌더링. 메뉴·FAQ·커리큘럼만 클라이언트 컴포넌트.
- 입력은 FAQ 로컬 검색뿐이며 이름·연락처·파일 수집 없음.
- 외부 폰트·이미지 호스팅·분석 서비스·업무 API 호출 없음. 로컬 AI 생성 콘셉트 이미지와 자체 SVG·CSS를 사용하며 Next.js Image로 최적화한다.
- 키보드 포커스·건너뛰기 링크·aria-expanded·reduced-motion·모바일 메뉴 Escape 처리.
- 주차 데이터는 원문 제목·순서를 대조하고 12+12건 및 편성 72시간/교육활동 68시간을 확인.
- 검토용 상태로 검색 색인 제한. 공식 도메인 미확정으로 sitemap·canonical 절대 URL은 미생성.

## 디자인 개편

- 제공된 U PLEAT 캡처 PDF의 시각적 구성에서 대형 타이포그래피·검은 히어로·넓은 여백·행 단위 구분선을 참고했다.
- 기존 AI 융합대학 메뉴·교육과정·24주 로드맵·FAQ·준비 상태는 유지한다.
- 참고 사이트의 로고·문구·솔루션명·이미지는 사용하지 않는다. 자세한 내용은 `docs/editorial-design.md` 참고.

- `artifacts/frontend-verification.json`에 실제 검사 결과가 기록됩니다.
